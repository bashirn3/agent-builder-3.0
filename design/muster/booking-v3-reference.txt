This Api is used to create or update online reservations.

## Creating a new reservation

* Create a pending reservation (a pending reservation is valid for only 15 minutes)
* Create a B2C Customer
* Create the actual reservation

## Reservation group ID

groupId identifies a booking and groups its reservations together. It is returned by POST /v3/{chainId}/PendingReservations and by GET /v3/{chainId}/Reservations/search/{bookingNumber}.
Use the returned groupId when handling reservation. Reuse the same groupId for every reservation that belongs to the same booking.
groupId is required even when the booking contains only one reservation.

## Updating an existing reservation

* Get a reservation by Uid
* If station or time changed, create pending reservation (a pending reservation is valid for only 15 minutes)
* Update the B2C Customer
* Update the actual reservation

## Calendar free times

Calendar returns slots available for station in groups of full hours. For example:
* A station opens at 8:30
* The first hour returned is 8:00
* But the first slot starts 8:30 (assuming it's available)

Single time can contain multiple slots. Like 8:00 can have two resources and both of those are returned.
Different resources might have different slot durations.

## Creating an online payment

* Retrieve online payment methods
* After the user has selected a method, update the B2C Customer with the selected payment method
* Create the actual payment
* Create a form POST based on the returned URL and form parameters
* The user will be redirected to the online payment provider
* Once the payment is complete (or has ended in a cancellation/rejection/error), the user will be directed back to the URL defined in the station's online booking settings
