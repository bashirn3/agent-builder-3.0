Responsive
≥1180px editor and playground split 50/50. 900–1180px editor 46% with a 420px floor. <900px switch to the two-tab mobile shell — never scale the split down. Conversation column caps at 660px for line length. Composer and field editors use dvh plus visual-viewport insets.
Behaviour
Draft vs saved. The workspace holds one draft per instance. Mobile field editors return values to that draft with Done; Cancel abandons only that field session. Save version is the only thing that persists, on both platforms.
Lock. Lives in the editor action area next to Save version, secondary weight. With unsaved changes it offers Cancel or Save and lock, and locks only after the save resolves; on failure the edits and the error stay. Unlock is one click, available in the lock strip and in version history.
Versions. Selecting a row previews only. Restore loads the text into the draft, needs unlocking, and warns before replacing an existing draft.
Testing. The context bar reports the last saved version, not a claim about the open conversation. Saving shows "Saved as vNN" with Start a fresh test and never clears the conversation. An unsaved draft shows its own banner.
Instances. Switching Original/Copy with a draft present asks first, and swaps conversation with configuration so one agent's chat is never shown under the other.
Motion
150–200ms ease on: Add instructions expand, version history drawer/sheet, editor panel on lock/unlock, spinner and save feedback. Nothing else. All suppressed under prefers-reduced-motion; no interaction waits on a transition.
Taken from each Mobbin reference
01 login. The narrow centred column with a large quiet title, pill-shaped inputs and one full-width dark action; I kept that composition and rhythm and dropped the social buttons, sign-up line and legal footer.
02 desktop playground. Labelled configuration stacked above a tall monospace prompt box, a thin vertical rule to the conversation, save state sitting beside the save action, and the quiet right-hand pane with its own slim context bar. I dropped the model row, tools, variables chips and the platform sidebar.
03 mobile instructions. The focused single-field editor: centred title, circular close, short helper line under the field, and one unmistakable commit control. I moved commit to the top bar as Done so the keyboard cannot cover it, and kept version saving out of the field editor.
04 mobile chat. Conversation density and rhythm: light grey right-aligned user bubbles against low-chrome agent text, a small action row under agent replies, and the pill composer with a circular send control. I kept Copy only, and dropped voice, attachments and the consumer account controls.
