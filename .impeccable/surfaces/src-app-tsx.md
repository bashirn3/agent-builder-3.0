## Direction contract

THESIS: A reduced Wasup shell around one K1 Katsastus Playground. It refuses a platform dashboard and the older browser-window tester; desktop is sidebar + inspector + contained agent tester on a dotted canvas.

OWN-WORLD: Existing restrained Wasup neutrals (ink `#1d1d1b`, canvas `#f7f7f4`, white surfaces, thin rules). Inter. Controls 40×8. Chatbase-measured columns (256 / 48 / ~455 / ~408) without Chatbase branding, trial chrome, or a new palette.

STORY: A reviewer opens the development prototype, edits instructions or the opener as a local draft, saves or discards, and runs a mocked test. Unfinished Activity and Leads stay visible but unavailable.

FIRST VIEWPORT: Desktop: 256px Wasup sidebar (Playground active; Activity and Leads marked unavailable), 54px agent header, ~455px inspector with sticky Discard/Save only when dirty, dotted canvas, ~408px contained tester. Mobile: Test first; Refine is a focused overlay. No login gate in this milestone.

FORM: Brief-pinned from `design/chatbase-audit/report.md` and `design/chatbase-flow-research/handoff/README.md`. Live Playground is primary. Code-led. Historical Mobbin is supplementary.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
